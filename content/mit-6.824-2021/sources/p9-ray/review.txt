语义重点与校注
- task caller owns returned DFut；producer、physical data location、owner 不能互换。borrower 可拥有它自己新调用产生的 future。
- 普通 DFut 参数在被调函数执行前隐式转成值；SharedDFut 传句柄，不为路由无谓搬运大数据；论文抽象 API 不冒充现代 Ray Python 同名接口。
- actor 私有可变状态与共享不可变对象分开；只重启 constructor 不承诺恢复 Counter 的旧数值或所有请求队列。
- TaskID 原文为父 TaskID+调用序号之 hash，不把讲义加号简记当完整字符串算法。
- pending task location 在每次转交前本地同步更新；object-copy directory 可异步；ownership 不是取消元数据。
- 旧 distributed task leases 与新 worker/resource lease 分开；最坏 RTT 不保证优于基线，资源可复用时才有短路径。
- 引用计数不等于局部变量数，submitted task/borrower/nested/local/lineage 各有寿命；borrower 子集合由 owner 合并追踪，不能自己抹除。
- 值可释放不等于 Task 字段可回收；lineage count 按依赖 Task 记录被回收才减，避免提前丢配方。
- owner 存活时优先 secondary、否则重跑必要链；owner 死亡时 fate sharing 而不是另选主保留旧表。
- 返回 future 给祖先可向上传播 fate sharing；不只限后代。root driver 仍是应用边界。
- GC 可追踪 actor 保存 borrowed DFut，但 §4.3 透明 owner 恢复论证不覆盖这种保存；不能混淆两种承诺。
- 讲义 195–198 行把 W2 crash 写在 loss-of-owner 下，与既定角色不自洽；以 200–208 行和论文 Figures10–11 对齐。
- FAQ 87–88 行说 borrower 可改 Ray object，与论文不可变对象冲突；正文指出冲突，不用它扩大对象可写语义，也不捏造作者澄清。
- 实验按作者设置报告：Fig14 故障5秒/心跳1秒；Fig15 旧租约5秒故障与 Ownership10秒故障分开；Redis CP 为应用层，不是全 actor 自动快照。
- TLA+ 是有限抽象模型检查，排除 first-class futures 与 actors，未声称完整实现证明。
- notes 与 materials 分工：notes 推导、反例与自测；materials 承担 API/RTT/树协议/数据路径/实验条件/相关工作和附录细节。必要衔接通过站内链接。
