二、Lab 1 MapReduce
要求：lab-mr-2026.html，Your Job / tests / rules。
代码：src/mr/{coordinator,worker,rpc}.go；src/main/mr{coordinator,worker}.go。
- MakeCoordinator(sockname string, files []string, nReduce int) *Coordinator。
- Worker(sockname string, mapf func(string,string) []KeyValue,
         reducef func(string,[]string) string)。
- main/mrcoordinator.go：socket 为第一个用户参数，之后是输入文件。
- main/mrworker.go：插件为第一个用户参数，socket 为第二个。
- 官方要求 worker 任务超时使用 10 秒；只有一个协调器，测试 worker 失败恢复。
- 测试：src/mr/mr_test.go，Wc、Indexer、MapParallel、ReduceParallel、
  JobCount、EarlyExit、CrashWorker。
- 验收入口：在 src 下 make mr；筛选示例 make RUN="-run Wc" mr。

三、Lab 2 KV + lock
要求：lab-kvsrv-2026.html，四节：可靠 KV、可靠 lock、丢消息 KV、不可靠 lock。
代码：src/kvsrv1/{client,server}.go、rpc/rpc.go、lock/lock.go；src/kvtest1/kvtest.go。
- IKVClerk：Get(string) (string, rpc.Tversion, rpc.Err)；
  Put(string,string,rpc.Tversion) rpc.Err。
- rpc.Tversion 为 uint64；PutArgs 包含 Key/Value/Version。
- 版本匹配才更新并递增；创建新键使用 version=0；无键且 version>0 返回 ErrNoKey。
- Clerk 首次 RPC 收到 ErrVersion 可确定未执行；重发后收到 ErrVersion 返回 ErrMaybe。
  ErrMaybe 是 Clerk 层错误，不应由服务器当成写入结果返回。
- Lock：MakeLock(ck kvtest.IKVClerk, lockname string)、Acquire()、Release()。
- 验收：make kvsrv1 与 make lock1；两者必须分别覆盖可靠与不可靠网络。
- 不把旧 Get/Put/Append 接口或请求编号去重教程当作本版要求。

四、Lab 3 Raft
要求：lab-raft-2026.html，3A election / 3B log / 3C persistence / 3D log compaction。
代码：src/raft1/raft.go、src/raftapi/raftapi.go、src/tester1/persister.go。
- Make(peers []*labrpc.ClientEnd, me int, persister *tester.Persister,
       applyCh chan raftapi.ApplyMsg) raftapi.Raft。
- raftapi.Raft：Start(interface{}) (int,int,bool)、GetState() (int,bool)、
  Snapshot(int,[]byte)、PersistBytes() int。
- ApplyMsg：CommandValid/Command/CommandIndex；
  SnapshotValid/Snapshot/SnapshotTerm/SnapshotIndex。
- Persister：Save(raftstate,snapshot []byte)、ReadRaftState、ReadSnapshot 等。
- 不实现论文 §6 成员变更；Snapshot 与 InstallSnapshot 属于 3D。
- src/raft1/raft_test.go 包含 3A/B/C/D 各组，含 TestSnapshotInit3D。
- 验收：make raft1；分阶段 make RUN="-run 3A" raft1 等。

五、Lab 4 RSM 与 KV
要求：lab-kvraft-2026.html，A RSM / B KV without snapshots / C with snapshots。
代码：src/kvraft1/rsm/rsm.go、src/kvraft1/{client,server}.go。
- StateMachine：DoOp(any) any、Snapshot() []byte、Restore([]byte)。
- MakeRSM(..., maxraftstate int, sm StateMachine) *RSM。
- Submit(req any) (rpc.Err, any)；无法继续的领导者请求向上报告 ErrWrongLeader。
- KV 继续使用 Lab 2 的 Get/versioned Put 语义；Clerk 需找 leader。
- C 不只是 KV 的快照，还包括 RSM 触发快照、恢复和接收快照 ApplyMsg。
- 代码中 rsm.go 的注释写 persister.SaveStateAndSnapshot，但实际类型只有 Save；
  不把残留注释中的旧名字复制到教程。
- 已核对 TestRestartReplay4A、TestShutdown4A、TestRestartSubmit4A、
  RSM TestSnapshot4C 与 KV TestSnapshotRPC4C 等测试存在。
- 验收：make rsm1 + make kvraft1。
  A：make RUN="-run 4A" rsm1。
  B：make RUN="-run 4B" kvraft1。
  C：make RUN="-run 4C" rsm1，以及 make RUN="-run 4C" kvraft1。

六、Lab 5 Sharded KV
要求：lab-shard-2026.html。
- A Moving shards；B Handling a failed controller；C Concurrent configuration changes；
  D Extend your solution。D 是官方实验的一部分，本自学路线将其列为进阶，
  不能把“自学可后做”说成“MIT 不要求做”。
- src/shardkv1/shardctrler/shardctrler.go：InitConfig、Query、ChangeConfigTo、
  InitController；构造时使用 kvsrv1.MakeClerk 存储控制器状态。

  以及 FreezeShard、InstallShard、DeleteShard。

- 分片组使用 Lab 4 的 RSM/Raft；控制器使用 Lab 2 的 KV。
  用复制 KV 存控制器配置属于 D 的一种扩展方向。
- 本版控制器不是旧版 shardmaster Join/Leave/Move/Query Raft 服务。
- 已核对 TestInitQuery5A、TestRecoverCtrler5B、TestConcurrentReliable5C、
  TestAcquireLockConcurrentUnreliable5C 和 PartitionRecovery 测试存在。
- 验收：make shardkv；可筛选 5A/5B/5C；Makefile 为此包设置 -timeout 15m。
