# 模型选择：先保证比较公平，再解释欠拟合与过拟合

## 1. 训练好，不等于预测好

训练的直接任务是让已有样本上的损失变小；我们真正关心的是模型遇到**同一目标场景里的新样本**时是否仍然有效。这两件事不能用一个数字代替。

设模型参数为$\theta$，样本为$(x_i,y_i)$，损失$\ell(f_\theta(x_i),y_i)$是一个标量。对含$n$个样本的训练集：

$$
\begin{aligned}
\widehat R_{\mathrm{train}}(\theta)&=\frac1n\sum_{i=1}^n\ell(f_\theta(x_i),y_i),\\
R(\theta)&=\mathbb E_{(x,y)\sim P}[\ell(f_\theta(x),y)].
\end{aligned}
$$

前者能计算；后者是目标分布$P$上的期望，不能拿有限数据精确求出。独立留出集给的是**估计**，不是泛化保证。若部署分布变了，留出估计也可能不适用。

自拟例子：六次公平硬币结果为`1, 1, 1, 1, 0, 0`，只会预测1的模型在训练集错$2/6=1/3$；面对下一次独立抛掷，错误概率仍为$1/2$。训练误差低于真实误差，不需要复杂神经网络才能发生。

“泛化差距”常指留出误差减训练误差；它不是泛化误差本身。模型A训练/验证损失为`0.01/0.20`，模型B为`0.30/0.31`，B差距更小却未必更好；按事先确定的验证损失指标，应选A。

## 2. 三个数据集合，三种权限

| 数据 | 可以影响什么 | 不可以承担什么 |
| --- | --- | --- |
| 训练集 | 梯度更新、预处理统计量、特征词表等拟合状态 | 单独证明泛化良好 |
| 验证集 | 模型结构、学习率、正则强度、早停轮数等选择 | 伪装成从未参与选择的最终评估 |
| 测试集 | 配置锁定后估计最终系统表现 | 每轮挑模型、挑阈值、挑随机种子 |

学习率、网络宽度、Dropout概率不是梯度直接学习的参数，但只要根据验证成绩改它们，验证集就参与了选择。反复试很多方案也会对验证集过拟合，所以要记录尝试，而不是只展示最漂亮的一次。

**早停也是模型选择。** 在第10、20、30轮中按验证指标选第20轮，应保留第20轮的参数快照，而不是训练结束时的第30轮参数。最后测试若不理想，再据此调参，就不能继续称这个测试集“未参与选择”。

数据足够时先划分三份；数据少时，在开发数据内部做$K$折交叉验证：每次用$K-1$折拟合、一折验证，重复$K$次。各折必须重新初始化模型、重新拟合预处理器。选择完成后可用开发数据重训，再用保留测试集做最终评估。它节省固定验证划分造成的数据浪费，但需要$K$次训练，也没有消除调参偏差。

## 3. 切分不只是一行随机打乱

![先划分数据，再拟合预处理，验证选择与测试隔离](assets/selection-boundaries.svg)

图为编者自绘：箭头表示允许的信息流，不是某次实验的测量结果。重点是**预处理状态也属于模型**。

### 3.1 训练统计量必须停在边界内

标准化是$z=(x-\mu)/\sigma$。训练集`[0, 2]`的均值为1，按总体定义计算的标准差为1；验证样本`10`应被变换为9。若先把三点合起来求均值，就变成4，验证集改变了训练表示——即使没有读取验证标签，也已跨过评估边界。

```python
import torch

train = torch.tensor([0.0, 2.0])
valid = torch.tensor([10.0])
mu = train.mean()
sigma = train.std(correction=0)
print(mu.item(), sigma.item(), ((valid - mu) / sigma).tolist())
# 解析预期：1.0 1.0 [9.0]。
```

这是有意避开零方差的机制小例，不是完整预处理实现。真实流水线要预先规定常量列策略，并只用训练统计识别常量列。填缺失值的均值、中位数、PCA方向、特征筛选、目标编码同样需要在每个训练折内拟合；验证/测试只调用已拟合的变换。

固定规则如单位换算、由业务事先定义的编码不等于“用全数据拟合统计”。区分依据是：该步骤是否通过本次数据学习状态，而不是它是否叫“数据清洗”。

### 3.2 划分单位要匹配部署问题

- 同一患者多次记录若落入训练和验证，模型可能识别人而非疾病。目标是新患者时，应按患者分组切分。
- 目标是预测未来，应按时间划分，并确保特征在预测时刻已经可获得；不能把未来统计回填过去。
- 原图及其裁剪、同一文档的近重复片段不能随机分到两边后假装独立。
- 类别比例、样本量、重复处理规则需要记录。随机种子能复现划分，但不能修复错误的划分单位。

这些是基于本节“独立留出”原则的工程补充，不是已经核实的课堂案例。

## 4. 用多项式分清表达能力与优化能力

对单特征$x$构造$\phi(x)=[1,x,x^2/2!,\ldots,x^d/d!]$，预测为$\hat y=\phi(x)^\top w$。它对$x$非线性，但对待学习参数$w$仍然线性。

| 对象 | 形状 |
| --- | --- |
| 一批原始输入 | $(B,1)$ |
| 最高$d$次的特征矩阵$\Phi$ | $(B,d+1)$ |
| 权重$w$ | $(d+1,1)$ |
| 预测和标签 | 均为$(B,1)$ |

第一列常量1已经承担偏置，额外加偏置会重复参数化常量项。输入$x=2$、三次特征为$[1,2,2,4/3]$；最高次数3不等于“只有3个参数”。教材代码的20列从$x^0$开始，最高是19次。

自拟无噪声三点`(-1,1), (0,0), (1,1)`：常量模型的最小均方误差在$\hat y=2/3$取得，MSE为$2/9$；二次模型$\hat y=x^2$可以全部拟合。这里确实存在表达能力不足，而不是训练轮数不够。加入噪声后，高次数可能把噪声也拟合掉，训练更好不保证新点更好。

若较复杂的模型包含简单模型的全部函数，那么**充分求到全局最优的无正则训练目标**不会更差。但有限步SGD、不同初始化、不同正则或数值病态会破坏这个比较前提，不能用“理论训练误差应更低”否定真实训练曲线。

## 5. 公平曲线诊断：先检查仪表，再判断模型

先约定同一批评估样本、同一参数快照、同一损失定义和同一模型模式，再看曲线：

1. **统一指标。** 两边都报告每样本平均的数据损失；不要一边含L2惩罚、一边不含。分类另报准确率，两者可能不同步。
2. **统一评估状态。** 训练集诊断曲线也可以在`eval()`模式、关闭随机增强后重算；不要把训练期Dropout损失与验证期无Dropout损失直接比较。
3. **统一时间。** 训练期间累计的是多个参数版本的损失，验证常用epoch末参数；若要研究泛化差距，额外用同一个epoch末快照评估两边。
4. **统一权重。** 最后一个batch通常更小，按样本数加权，而非对batch均值再等权平均。例如batch损失和/数量为`4/4`与`9/1`，全体均值是$13/5=2.6$，不是$(1+9)/2=5$。
5. **统一比较预算。** 比模型容量时固定划分和指标，记录训练步数、学习率调度、早停规则、种子；若某模型训练未收敛，结论应写“当前预算下”，而非“表达能力差”。

| 公平重算后的观察 | 可以提出的假设 | 下一步最小排查 |
| --- | --- | --- |
| 两边都高且下降停滞 | 欠拟合、优化失败或数据/标签问题 | 先确认loss/梯度/更新；能否拟合一个很小子集 |
| 训练继续下降，验证先降后升 | 过拟合迹象 | 固定选择规则，比较早停、L2、更多独立数据 |
| 两边都剧烈振荡或非有限 | 步长、尺度或数值问题 | 查输入、梯度、学习率；不是先加正则 |
| 验证优于训练 | 可能是训练扰动、指标口径不同或验证更容易 | 同模式同快照重算，并查划分 |
| 验证忽然近乎完美 | 可能确实简单，也可能泄漏 | 查重复样本、标签混入特征、全量预处理 |

以上不是一张“看到曲线就自动诊断”的判决表。参数多、训练久、差距大都不能脱离验证表现和数据条件单独判好坏。

## 6. 自测：先写理由，再展开

<details>
<summary>验证损失最低的模型差距最大，是否应排除？</summary>

不应仅因差距排除。按预先定义的验证指标选择，同时排查泄漏、估计波动和选择次数。泛化差距小可以只是训练和验证都很差。

</details>

<details>
<summary>只用全部样本的特征均值、不碰测试标签，为什么也不合适？</summary>

测试特征影响了预处理状态，系统使用了原本声称未见的新样本信息。在这里的独立留出评估设定下，应仅在训练部分拟合；每个交叉验证折也要重新拟合。

</details>

<details>
<summary>三点二次例子的常量最优预测、MSE分别是多少？</summary>

标签均值为2/3；平方误差为1/9、4/9、1/9，平均为2/9。增大训练轮数不能让常量函数同时等于0和1。

</details>

<details>
<summary>AI可以怎样帮助这一步，而不代做实验？</summary>

提供你自己的切分规则、损失聚合公式和两条曲线，请AI检查泄漏路径与比较口径。保留自己实现训练循环、选择超参数、解释最终失败曲线的任务，不索要一份完整训练答案。

</details>
