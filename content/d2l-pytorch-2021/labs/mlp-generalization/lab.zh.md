## 任务 1：MLP 从零与简洁实现、激活和梯度

**任务 id：`mlp-generalization-1`**

### 输入与路线

先做局部等价性，再复用上一实验真实 Fashion-MNIST 的固定训练/验证索引：257训练、73验证、像素0–1、标签long；不要重新用官方测试集调参。CPU起步：`784→64→10`、ReLU、B64、SGD学习率0.01、10轮、seed17；这是缩小版，不声称复现教材256隐藏单元与10轮结果。

从零版自己表示权重、偏置和前向，可用autograd；简洁版用`nn.Linear`。若手写权重是$(d,h)$，框架对应权重是$(h,d)$，复制时转置，偏置也要复制。**相同seed不等于相同参数**：两个构造过程可能消耗不同数量的随机数。

| 对象 | 形状/含义 |
|---|---|
| 输入 $X$ | $(B,784)$，保留batch轴 |
| 隐藏激活 $H$ | $(B,64)$，$H=\operatorname{ReLU}(XW_1+b_1)$ |
| 输出 $O$ | $(B,10)$，未归一化logits；交给交叉熵 |
| 标签 $y$ | $(B,)$，不是one-hot；B=1也不能丢掉batch轴 |

### 本地记录与自检与验收

1. 用float64小网络`2→3→1`、B3、mean MSE、SGD学习率0.05，固定同一组参数和输入，比较两实现前向、各参数梯度、一次更新，建议`atol=rtol=1e-10`。ReLU检查点避开预激活0；不能把不同零点导数约定误判成实现错误。
2. 回到分类，保持相同初值、batch顺序、目标和更新次数，记录两实现损失差与参数差。实数运算不要求跨设备逐bit相同；局部float64核验与float32训练容差分开声明。
3. 激活对照只换ReLU/Sigmoid，初始化对照只换权重标准差0.01/1.0或Xavier；每次从头开始。记录第0步、第一步、末轮各层激活均值/标准差、零值或饱和比例、梯度范数与参数变化量。不要一次换激活、初始化、学习率后归因给其中一个。
4. 额外用全零初始化作**故障夹具**，解释对称性与ReLU零点为何阻碍学习，不把它作为推荐配置。Xavier的方差推导有独立性/近似线性假设，不保证任意深网稳定。

**判据**：局部同权重核验通过；梯度/输出有限，真实数据来源可信；训练循环确实更新参数；能用日志解释差异。不设准确率排名，不要求每轮单调下降。数据不可用时，局部核验可完成，但真实Fashion训练必须明确未完成。

## 任务 2：欠拟合、过拟合与单变量正则化

**任务 id：`mlp-generalization-2`**

### 固定小数据与对照矩阵

用独立随机生成器seed17，一次生成160个20维标准正态输入；前32个训练、后128个验证。标签为下式，噪声独立、标准差0.1。保存实际索引/数据哈希，后续比较不重抽数据。

$$
y=x_0^2+0.5x_1+\epsilon,
\qquad \epsilon\sim\mathcal N(0,0.1^2).
$$

模型输出与标签均为$(B,1)$，避免$(B,)$与$(B,1)$广播成$(B,B)$。使用mean MSE、B16、SGD学习率0.03、无momentum、300轮。线性模型作为容量受限参照；MLP为`20→64→1`、ReLU，默认Linear初始化记录清楚。

| 实验 | 模型 | weight_decay | 隐藏层Dropout |
|---|---|---:|---:|
| 容量参照 | 线性 | 0 | 0 |
| 共用基线 | MLP | 0 | 0 |
| 衰减对照 | 同一MLP | 0.01，仅weight | 0 |
| 暂退对照 | 同一MLP | 0 | 0.2，ReLU之后 |

MLP三组从独立的相同参数快照开始；数据顺序随机流与Dropout随机流分开，Dropout不能顺便改变下一轮shuffle。固定预算之外，如需要延长训练以分辨优化不足，所有配对组一起延长并保留原结果。可再用seed18、19重复以评估波动，但不可只报告最好seed。

### 目标、指标与模式

权重衰减优化的是数据损失加惩罚，验证指标只计算数据损失。这里的无momentum SGD中，`weight_decay=λ`与加入$\lambda\|W\|^2/2$的梯度对应；不要同时手加L2和设置优化器衰减，也不能直接把该等价性外推为AdamW与Adam完全相同。

每轮分别记录：训练时优化目标、`eval`模式下完整训练集MSE、`eval`模式下验证MSE、权重范数。只有后两项适合直接比较泛化差距。训练模式的Dropout损失包含随机失活，不能与关闭Dropout的验证损失机械比较。

- `train()` / `eval()`决定Dropout等模块行为，**不控制是否记录梯度**。
- `no_grad()`控制自动微分记录，**不会关闭Dropout**。
- 验证应同时用`eval()`与`no_grad()`，结束后恢复训练模式；验证不调用backward/step，也不改变参数或既有梯度。

**本地记录与自检**：四组完整曲线、配对配置差异表、末轮训练/验证MSE、范数、故障诊断。训练和验证都高时，先排除学习率/梯度/训练预算问题，再谈欠拟合；训练低而验证高是过拟合信号，不是证明数据一定正常。Dropout或衰减可能无改善甚至变差；如实说明证据与限制就是有效结论，不追求预定“赢家”。

## 任务 3：Ames 房价预处理、K折与导出

**任务 id：`mlp-generalization-3`**

- 测试文件`kaggle_house_pred_test.csv`：1459行、80列，无标签；两份文件的SHA-1校验值见页底。

自己运行时重新核hash及列名，数据放运行缓存，不放`content/`。公开可取不等于可任意再发布；Kaggle数据规则与教材源码许可分开。教材把训练/测试拼接后处理是教学简化，本实验明确改为**先分折，再折内fit**，不拿全体无标签特征估计验证分布。

### 预处理合同

每折仅用训练行学习以下状态，再原样transform该折验证行。`Id`只作追踪，`SalePrice`只作标签，均排除于特征。数值/类别列的判定策略需固定并留存，不假定整数列一定具有连续数值语义。

| 类型/边界 | 规定行为 |
|---|---|
| 数值缺失 | 训练折非缺失值均值插补；整列全缺失时填0，并记录该列 |
| 缩放 | 用训练折非缺失值的均值与总体标准差（`ddof=0`）标准化，均值插补后的缺失位置变0；不把验证值纳入统计 |
| 常量列 | 标准差为0时设缩放分母为1；训练值变0，不产生NaN |
| 类别缺失 | 显式`__MISSING__`，与真实字符串冲突时使用不冲突的内部标记 |
| 类别词表 | 只收训练折类别，另保留`__MISSING__`、`__UNK__`；固定列顺序 |
| 未知类别 | 验证/测试新类别进`__UNK__`，不扩充词表；不重新fit |
| 张量 | 全部转换为一致float32、无object dtype、无NaN/Inf |

各折可能得到不同特征维数，这是合法的；**每折必须重建预处理器、模型、优化器**，不能复用上一折Adam状态。禁止用验证标签设初始化偏置、选择填充值或提早修改训练输入。

### K折、目标与指标

起步小规模：seed17随机排列1460行取前257，分3折为86/86/85；按原始行位置回填OOF预测。完整基础：全部1460行、5折，每折292行。切分器还必须通过11行/3折的4/4/3夹具，不能只在刚好整除的数据上看似正确。

每折使用线性`D→1`预测**自然对数价格**$z$，权重初始化0、偏置为该训练折$\operatorname{mean}(\log y)$；Adam学习率0.03、weight_decay=0、B64、30轮。训练目标是mean平方对数误差，评估报告其平方根。另报告训练折平均log价格的常量预测基线。该设计是教材4.10练习的编者选择，不是原代码“原价格MSE训练、裁剪预测后logRMSE评价”的逐行复刻。

令$e_i=z_i-\log y_i$、$n_k$为第$k$折验证数，正确总体指标是：

$$
\begin{aligned}
S_k&=\sum_{i\in V_k}e_i^2,\\
\operatorname{OOF\ logRMSE}
&=\sqrt{\frac{\sum_k S_k}{\sum_k n_k}}.
\end{aligned}
$$

不能平均每batch RMSE，也不能把各折RMSE的算术均值当成总体OOF指标。每折分数可另列；OOF必须每个选中样本恰好预测一次，无尾部遗漏。例：三样本误差`[0,0,3]`，分2+1两折，总体应为$\sqrt3$，不是$(0+3)/2=1.5$。

所有训练标签须为有限正数；本任务用`log`而不是`log1p`，输出价格为$\exp(z)$。导出前检查指数结果仍为有限正数，不能悄悄用裁剪掩盖爆炸。若你另做原价格MSE基线，应标记目标不同，并记录评价前预测被裁剪的数量；裁剪只用于某个metric定义不等于导出价格自动合法。

### 输出与验收

1. 保存每折训练/验证索引哈希、处理器状态摘要、特征顺序、初始化seed、逐轮指标、OOF逐行预测及覆盖计数。B64与B32评估的全样本指标在浮点容差内相同。
2. 反事实夹具：只改变验证特征，训练折均值/方差/词表不变；只改变验证标签，在固定轮数且无早停的同配置重训中，模型参数不变，仅验证分数改变。不能用“代码里似乎没有引用”代替运行证据。
3. 冻结模型结构、超参和轮数后，用全部1460训练行重新fit预处理器、重建模型和优化器；测试只transform。5折是选型证据，最终全量训练分数不是测试分数。
4. 导出`Id,SalePrice`两列、1459行、`index=False`；Id顺序与原测试文件逐行一致且不重复，价格全为有限正数。导出再读回核对；若loader曾shuffle，需要用Id恢复顺序，而非把排序后的价格盲贴到原Id上。
5. 报告实际OOF分数与常量基线；没有低于基线就诊断，不编造提高。Kaggle上传、排行榜名次不作为基础验收条件。
