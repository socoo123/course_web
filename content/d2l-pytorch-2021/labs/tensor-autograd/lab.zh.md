# 张量、数据与自动求导

## 目标与边界

用能手算的小数据，把“形状是什么、数据从哪里来、梯度经过哪条路径、概率的分母是什么”变成可检查的程序行为。先预测，再运行，最后解释差异；不需要先补完三门数学课，也不要求论文阅读。

- **CPU 基础**：四项都可用 Python 脚本完成；需要 PyTorch、pandas，张量统一放 CPU，不依赖 `d2l`、Jupyter、外网或下载数据。
- **硬件扩展**：本实验不要求 GPU、CUDA、MPS 或性能排名。今后多设备实验另行说明；MPS 不是 CUDA。
- **历史竞赛**：本页与房价等历史竞赛无关，不下载竞赛数据、不提交排名、不沿用截止日期。

## 任务 1：形状、广播与矩阵运算

**task id：`tensor-autograd-1`**

来源：教材 2.1 的索引、reshape、广播及其练习；2.3 的矩阵乘法、归约和保留轴。下面的数值及检查组合为编者自拟。

### 固定输入

```text
A = [[1, 2, 3],
     [4, 5, 6]]              # 两个样本、三个特征
b = [10, 20, 30]             # 每个特征的偏移
c = [[100], [200]]           # 每个样本的偏移
W = [[1, 0], [0, 1], [1, -1]]
v = [2, -1, 0]
```

### 要做什么

1. 创建 CPU 浮点张量。预测并打印 `A[0]`、`A[0:1]`、`A[:, 1]`、`A[:, 1:2]` 的值和形状，说明整数索引与切片的差别。
2. 比较 `A.reshape(3, 2)` 与 `A.T`；再把 reshape 的结果恢复为原形状。说明为什么“元素个数相同”不代表“轴含义相同”。
3. 计算 `A+b`、`A+c`；按从右向左对齐的广播规则写出每一步的形状。另试 `A + [10, 20]`，记录异常类别和不兼容的轴；不要为了让它能跑而随意 reshape。
4. 计算 `A*v`、`A@v`、`A@W`。手算矩阵乘法结果中的一个元素，说明 `*` 与 `@` 分别做了什么。
5. 分别按 `dim=0`、`dim=1`、所有轴求和，再比较 `keepdim=False/True`。用每行元素和把该行归一化，确保除数按样本对齐。尝试不保留归约轴，解释此输入为何无法直接按行相除。

### 可观察验收

- 交一张“表达式 / 输入形状 / 预测输出形状 / 实际输出形状 / 轴含义”表；不只截图最终结果。
- reshape 往返保持元素顺序；转置与 reshape 不被当成同一操作。
- `A@v` 的每个元素与对应行的按元素乘积之和一致；`A@W` 的输出形状为 `(2, 2)`，手算的一格吻合。
- 全局求和与任一按轴求和后再求和一致；归一化结果为 `(2, 3)`，每行和接近 1。
- 非法广播作为明确的预期失败被记录；不能用捕获所有异常后继续的方式掩盖其他错误。

**陷阱**：`(3,)` 不是二维列向量；`sum(dim=0)` 消去的是轴 0，不是“保留第 0 行”；`reshape` 不保证永远不复制内存，本题不要求存储共享实验。

## 任务 2：先划分，再拟合预处理

**task id：`tensor-autograd-2`**

来源：教材 2.2 的微型表格、数值缺失填补、类别编码与张量转换；**训练/验证划分、冻结统计量及泄漏反例是编者工程补充，不冒称教材该节原题**。

### 固定输入

可直接用列表建立 DataFrame，或把下表录入内存 CSV。`NA` 表示缺失，不是字符串类别。

| id | rooms | area | district | target |
|---|---:|---:|---|---:|
| t0 | 1 | 30 | north | 100 |
| t1 | 3 | NA | south | 160 |
| t2 | NA | 50 | NA | 140 |
| t3 | 5 | 70 | north | 220 |
| v0 | 99 | 900 | west | 999 |
| v1 | NA | NA | north | 180 |

训练行固定为 `t0–t3`，验证行固定为 `v0–v1`，**不要随机重分**。`id` 只做追踪，`target` 是标签，二者都不得混入特征或特征统计量。

### 要做什么

1. 先拆出两个集合，分别报告原始每列缺失计数、行 id 和样本数。验证集缺失计数可以报告，但不能拿来拟合预处理。
2. 仅从训练集 `rooms`、`area` 的非缺失值计算各列均值；保存统计量，再用同一组均值分别填补训练和验证特征。不要求标准化或训练预测模型。
3. 训练集非缺失 `district` 的词表按字母序排列；预留两个编者定义的类别 `__MISSING__` 和 `__UNKNOWN__`。缺失进前者，验证中未见类别进后者。两集合采用同样列名、顺序和 one-hot 宽度；不要为了发现 `west` 而在合并数据上拟合词表。
4. 按 `rooms, area, 类别列` 的固定次序生成数值特征，再转成 CPU `float32` 张量。标签单独转换，形状统一为 `(样本数, 1)`。
5. 做一次泄漏对照：另算“合并训练与验证后拟合”的错误均值，但不得用它覆盖正确流程。再把 **v0.area 从 900 改成 9000**，从原始输入重新执行正确流程，比较训练拟合状态、训练输出、v1 的缺失填补值是否改变。

### 可观察验收

- 训练/验证 id 交集为空，样本数为 4 和 2，顺序可追溯。
- 统计量对象只有训练数值列与训练词表；能说出每个均值的分子、分母及忽略的缺失位置。
- 两集合特征列完全对齐，本例特征形状分别为 `(4, 6)` 与 `(2, 6)`；标签为 `(4, 1)` 与 `(2, 1)`。特征均为有限数值，每行类别块恰有一个 1。
- v0 的 `west` 进入未知类别，t2 的缺失进入缺失类别；未知不能被误当作缺失。
- 修改验证异常值后，正确训练均值、词表、训练张量和 v1 填补值不变；错误合并均值会变。保留这个对照作为“没有泄漏”的可观察证据。

**陷阱**：不要对含字符串的整张表直接 `mean()`；不要分别 `get_dummies` 后默认列顺序相同；不要让标签参与填补或均值拟合。本例训练数值列都有观测值；若换成整列缺失，须明确拒绝或另订仅依赖训练的策略，不能拿验证均值补救。

## 任务 3：手算、反向传播与梯度状态

**task id：`tensor-autograd-3`**

来源：教材 2.4 的导数、偏导和链式法则；2.5 的标量/非标量反传、梯度累积与分离计算。函数和输入作了改编。

### 固定输入与任务

1. **标量链式法则**：取标量 `s=2`，定义 $f(s)=(3s-1)^2$。先列中间变量及每条局部导数，手算 $df/ds$，再用 autograd 核对。不要只抄最终数。
2. **向量输入、标量损失**：取 $x=[1,-2,3]$，$a=[2,-1,1]$，$L(x)=\sum_i(a_i x_i)^2$。手算每个分量的偏导，再核对 `x.grad`，写出 `L` 和梯度的形状。`a` 是常量，不要求梯度。
3. **非标量输出**：令 $q=x\odot x$，权重 $w=[1,0,2]$。在独立实验中比较 `q.backward(w)` 与 `(q*w).sum().backward()` 得到的梯度。另说明 `q.sum()` 对应什么权重，为什么它不是“返回完整 Jacobian”。
4. **累积与清零**：在同一个叶子 `x` 上重复计算上面的 `L` 两次，每次重新前向建图。第一次反传后保存梯度快照，第二次不清零；第三次先清零再重新前向、反传。记录三份梯度，解释它们之间的关系。
5. **detach 对照**：重新建立干净叶子 $r=[-1,2]$。令 $u=r\odot r$，分别计算 $z=\sum_i u_i r_i$ 与 $z_{stop}=\sum_i\operatorname{detach}(u)_i r_i$。先手画路径并推导，再在两个独立计算图中核对前向值与梯度。指出被切断的是哪条路径，而不是说“整个 r 没梯度”。

### 约束与可观察验收

- 用 CPU `float64`、`requires_grad=True` 的浮点叶子；禁止 `.data`，不在参与求导的张量上做原地数值修改。
- 每次独立比较前重建叶子或明确清空梯度；重复反传按要求重新前向，不用 `retain_graph=True` 掩盖生命周期问题。
- 手算与 autograd 在约定容差内一致；非标量加权反传的两条实现等价，梯度形状与输入一致。
- 同一 `L` 的第二次累积梯度是第一次的两倍；清零后的第三次恢复为第一次。保存第一次时必须是真正快照，不能只保存 `.grad` 的别名。
- detach 对照前向值相同，但这组非零输入的梯度不同；解释差异来源。`detach()` 不是复制存储，本任务不修改它的返回值。
- 运行记录要区分“尚未生成梯度的 `None`”“已分配但清零的梯度”“数值非零的梯度”。

**陷阱**：整数张量不能这样求梯度；求导前把损失 `.item()` 会丢失张量计算图；`backward` 累积的是叶子的 `.grad`，不会自动更新参数。本题不写优化器，也不要求二阶导数。

## 任务 4：期望与条件概率的小实验

**task id：`tensor-autograd-4`**

来源：教材 2.6 的骰子抽样、频率、条件概率及期望。这里缩小抽样规模、另造有限样本与事件，不照搬教材图，也不引入医学解释或证明题。

### A. 先用确定数据核对统计逻辑

固定观测序列：

```text
[1, 2, 2, 3, 4, 4, 4, 5, 6, 6, 6, 6]
```

令 $X$ 为骰子点数，事件 $A=\{X\text{ 为偶数}\}$，$B=\{X\ge4\}$。

1. 报告 1–6 的计数、经验概率、样本均值；用“值 × 经验概率”的加权和复算均值。
2. 分别报告 $A$、$B$、$A\cap B$ 的计数；算出 $\widehat P(A\mid B)$ 与 $\widehat P(B\mid A)$，写明各自分母。不要求两个方向相同。
3. 给另一个条件事件 $C=\{X>6\}$，解释为什么这份数据无法估计 $P(A\mid C)$。返回明确“未定义/无条件样本”的状态，不把它填成 0 或加一个未经说明的小常数。

### B. 再用已知分布做抽样对照

理论分布规定为公平六面骰，每面概率 $1/6$。先从定义手算 $E[X]$、$P(A\mid B)$、$P(B\mid A)$，不要用 A 部分观测频率代替理论分布。

创建一个 CPU 随机生成器，种子固定为 **2021**，一次抽取 **600** 个独立、有放回的点数，再查看前 **12、60、600** 个样本前缀。可用 `torch.multinomial` 采样类别索引后映射为 1–6；必须明确 `replacement=True`。分别记录频率、样本均值、两个条件概率的分子分母及与理论值的误差。

### 可观察验收

- A 部分计数和为 12，频率非负且总和接近 1；样本均值与经验加权均值一致。条件事件没有样本时明确标记未定义。
- B 部分计数和分别为 12、60、600；每个前缀都来自同一条 600 次样本序列，不是每个规模重新抽样。
- 固定环境与相同生成器种子，从头重跑能得到相同计数；记录版本，不承诺跨版本或跨设备逐项相同。
- 把理论值、实际值、误差并列，并解释：样本更多通常有利于估计，但**单条样本路径的误差不保证单调下降**。不能以“不够接近”为由反复换种子；本题不设随机结果必须落在某个误差内的硬阈值。

**陷阱**：条件概率不是联合概率；有放回抽样不是六张卡各取一次；`torch.multinomial` 返回类别索引，而教材的 `torch.distributions.Multinomial` 示例返回计数向量，两种 API 不能混为一谈。
