# RNN、GRU与LSTM语言模型

## 学习问题：模型究竟记住了什么，又偷看了什么？

把一段字符流变成可复现的下一字符预测实验：先证明词表与窗口没有泄漏，再实现能沿时间传递状态的RNN，最后在相同数据上比较GRU、LSTM。短预算结果可以不好，但不能把错位标签、未来信息或不同分母造成的“低困惑度”当作模型能力。

本实验由你在本地用Python/PyTorch自行实现，程序、配置和学习记录仅供自己保存与自检；无需Git提交、推送、上交报告或上传本站，也不要求排行榜提交。个人学习与任务进度不作为教程完成条件，不由agent认证或追踪。

按[实验指导](#/c/d2l-pytorch-2021/lab/recurrent-language-model?v=guide)自行实现。本地使用Python/PyTorch练习。

## 任务1：先锁定文本，再锁定时间边界

**对应 `recurrent-language-model-1`。**

### A. 数据合同

使用教材注册的`timemachine.txt`，作品为H. G. Wells（Herbert George Wells）的 *The Time Machine*。教材下载文件为178979字节，SHA-1应为：

```text
090b5e7e70c295757f55df93cb0a180b9691891a
```

首行含`[1898]`，这是该文件的标题标记，不把它误称为作品初版年份。教材文件也不是当前Project Gutenberg #35下载物的逐字节副本；两者的页首、目录、标点与版本包装不同。不要以“同一本书”为由替换文件后继续沿用旧hash、位置或结果。准确下载入口及独立使用条件见页底。

### B. 固定划分与清洗合同

采用以下**编者评估方案**，不是声称教材本来就提供了train/validation/test划分：

1. 按文件原始行序读取，保存原始行号。每行以正则`[^A-Za-z]+`替换成一个空格，再`strip()`和`lower()`；删去清洗后的空行。保留标题、章标题等剩余文本，不另外做未记录的删改。
2. 设非空行数为$n$，边界为$a=\lfloor0.8n\rfloor$、$b=\lfloor0.9n\rfloor$。以半开区间划分：训练行`[0,a)`、验证行`[a,b)`、测试行`[b,n)`。这是小说顺序位置，不是随机打散后的比例切分，也不是现实时间戳。
3. **分别**把每段中的行变成字符后直接展平，段内不额外插入行间空格或换行。行内空格保留。此约定对齐教材字符展平方式，但会在换行处形成粘词，如`"time"`与`"traveller"`相接成为`"timetraveller"`；这不是自然语言规则。改为空格拼接也可以作为另一个实验，但须重新记录预处理版本、token位置与指标，不能混比。
4. 只用完整训练段拟合词表；保留`<unk>`，验证/测试未见字符映射到它，不扩充词表。记录词频同分时的排序规则与token→ID映射。未知字符即使在本语料某段恰好没有出现，也要用独立小例覆盖。
5. 每段独立构建X/Y窗口，Y始终比X向后一步。窗口的所有输入及最后一个目标都必须在该段内；不能先在全书造重叠窗口再随机切分，也不能借训练最后一字符预测验证首字符。
6. 记录每段清洗后行数、原始行号边界、字符数、实际使用位置与未使用尾部。调参只看训练/验证，测试封存；确定方案后才做一次最终测试。仅做小运行而未评估测试时，应直接写“测试未评估”。

本阶段小运行可在上述划分后取训练段前8192字符、验证段前2048字符，词表仍拟合**完整训练段**，不得声称只在8192字符上拟合。候选字符数不等于实际计分token数：一步移位、按batch分行、尾部不足一个窗口都会减少有效数，日志需保存真实分母。它只验证有限数据上的执行链路，不代表全书训练或泛化成绩。

### C. 两种采样都要检查

- **随机子序列采样**：相邻batch的第$r$行不保证来自相邻文本；每批初始化状态。记录窗口起点与随机种子，不按抽样后batch序号臆造连续性。
- **顺序分区采样**：将段内长流划成固定的batch行流；后一批第$r$行必须紧接前一批第$r$行。保持行身份，才能携带该行状态。每个epoch开始重新初始化；中间批次保留数值、分离计算图。
- 新段、换语料、行重排或batch行数变化，都不能机械沿用旧状态。小实验可明确丢弃不足整批的尾部，必须记账；如选择padding，则mask和有效token分母也成为合同的一部分。

验收时用带原始位置的短序列展示两批X/Y，说明“当前批的最后一个Y”如何成为“下一批同一行的第一个X”。随机采样时则展示为什么不能如此假定。

## 任务2：从零RNN与API必须讲同一种张量语言

**对应 `recurrent-language-model-2`。**

先读[LEC54原理](#/c/d2l-pytorch-2021/lec/lec54?v=notes)与[LEC55实现](#/c/d2l-pytorch-2021/lec/lec55?v=notes)。要求两条路线均完成：

- 从零路线自行写状态更新、输出投影、损失和状态接口；不复制整段教材训练循环作为自己的说明。
- API路线使用`nn.RNN`加输出层。循环层返回的`output`是每步隐特征，不是词表logits；必须投影到词表大小$V$。
- 用同一组小输入、初始状态与映射后的参数比较前向输出/末状态，以及同一个标量损失对输入或对应参数的梯度。初始化相同种子不等于参数相同；矩阵转置、双bias与时间优先展平都需明确。
- 两条路线均在实际文本上留下有限更新与生成记录；可用极短预算检查从零实现，再用API完成三模型公平比较。若只做了合成局部对照，不能写成从零模型真实训练完成。

设窗口长度为$T$、batch大小为$B$、隐维为$H$，固定`batch_first=False`：

| 接口 | 形状/含义 |
|---|---|
| 整数X与Y | `(B,T)`；Y为下一字符ID |
| one-hot输入 | `(T,B,V)`；转浮点后送入循环层 |
| 从零单层状态 | `(B,H)`，可用单元素tuple封装 |
| API单层状态 | `(1,B,H)` |
| API循环输出 | `(T,B,H)`，还没有词表维 |
| 投影后logits | `(T,B,V)`或时间优先的`(T*B,V)` |
| 对应目标 | `Y.T`按相同顺序展平为`(T*B,)` |

CE接收未经softmax的logits和整数目标。不允许只检查reshape不报错：把每个位置标成`(t,b)`，证明logits与目标逐项对应。

### 指标与裁剪

对所有有效目标token累计负对数似然。若$l_i$为第$i$个token的CE、$m_i$为有效标记：

$$
S=\sum_i m_i l_i,\qquad N=\sum_i m_i
$$

$$
\mathrm{CE}=S/N,\qquad \mathrm{PPL}=\exp(\mathrm{CE})
$$

自然对数对应`exp`；不能平均batch困惑度，也不能无权平均长度不同的batch均值。没有padding的固定窗口令$m_i=1$，`<unk>`仍是真实目标，不能当padding排除。$N=0$不能报告有限PPL。保存$S$与$N$，才能重算指标。

每次更新执行“清旧梯度 → forward与CE → backward → **全体可训练参数的全局L2范数裁剪** → optimizer step”。记录裁剪阈值、裁剪前范数、裁剪后范数及是否发生裁剪。逐参数单独限幅或逐元素clamp不等于全局范数裁剪；发现NaN/Inf应定位，不用裁剪掩盖。

把逐步训练时的统计与`eval()`、不建图、固定数据重新评分分开。验证时参数不更新，状态从本验证段零值开始；不能继承训练末状态。初末loss的比较应使用相同模式、同一token集合与同一分母约定。

### 生成记录

每次生成重置状态，以非空前缀逐字符预热，前缀已有字符不由模型改写。用最后一个前缀字符的输出预测第一个新字符，之后把自己的预测回送；不能把验证答案逐字回送再称为自由生成。记录前缀、其编码/未知token策略、checkpoint、greedy或温度/采样种子、新token数和**真实原样输出**。输出重复或不成句也照录，不拿教材样例或手写句子替换。

## 任务3：公平比较门控，不混淆层数与方向

**对应 `recurrent-language-model-3`。**

将RNN作为基线，比较单层、单向的小规模`nn.GRU`与`nn.LSTM`。保持同一原文、清洗/划分、词表、输入表示、窗口、样本预算、验证策略、优化器与裁剪约定。报告实际步数、seed、参数量、有效token数、CE/PPL和生成；相同$H$并不意味着相同参数量，因此不能宣称严格等容量优劣。短预算某模型较差并不构成一般结论。

允许用$H=32$、$B=8$、$T=32$、Adam学习率0.01、裁剪阈值1起步；15轮也只是可记录的小预算，不是通过阈值或最佳超参数。任何“更快”结论都需自己计时，并记录设备、线程、同步方式与计时范围；CPU小运行不能外推出GPU吞吐。

读[GRU](#/c/d2l-pytorch-2021/lec/lec56?v=notes)、[LSTM](#/c/d2l-pytorch-2021/lec/lec57?v=notes)、[深层RNN](#/c/d2l-pytorch-2021/lec/lec58?v=notes)与[双向RNN](#/c/d2l-pytorch-2021/lec/lec59?v=notes)，补上两类机制检查，不强求深层/双向都做长训练：

- $L$层、$D$方向的API循环输出为`(T,B,D*H)`，末状态为`(L*D,B,H)`；LSTM返回`(h,c)`，无投影时两者同形。单向$D=1$，双向$D=2$；输出投影的输入宽度也要随方向变化。
- `batch_first=True`只换输入/输出的batch与时间轴，不把状态改成batch优先。双向最后一个时间位置的输出不能整体当作两个方向各自的终态。
- 深层是在每个时间点将下层特征送入上层，不是把时间窗口加长。上层输入宽度通常为$D H$，不是原始词表大小。
- 双向机制只用于形状与可用信息分析。它可以对完整可见序列编码，**不能把用到未来字符的低CE/PPL放进因果语言模型排行榜，也不能声称它是无未来信息的自回归生成器**。

## 任务4：状态不断，梯度为什么要断？

**对应 `recurrent-language-model-4`。**

画出至少两个相邻窗口的时间展开图，标明共享参数、前向状态边和损失反向边。把下列操作区别开：

| 操作 | 状态数值 | 历史梯度路径 |
|---|---|---|
| 重置状态 | 丢弃过去值，重新置零 | 不连接前段 |
| `detach` | 保留当前值 | 切断到前面计算图的边 |
| `zero_grad` | 不改变状态 | 只清参数上累计的`.grad`，不切图 |
| 截断BPTT | 窗口内继续递推，可跨窗带值 | 损失不越过指定detach边界 |

LSTM的$h$和$c$都必须detach；只分离$h$仍可能通过$c$保留旧图。不要用`retain_graph=True`作为跨批报错的常规补丁。截断只限制学习信号回传的跨度，不等于“隐状态里只能有$T$步信息”，也不是完整BPTT的精确替代。

另外设计一对序列：前缀完全相同，只改未来位置。固定参数与初始状态、关闭dropout，比较前缀位置的输出。单向模型在该位置应不变；构造有非零反向依赖的双向模型应变化。解释下一字符任务中的目标$y_t=x_{t+1}$怎样进入反向分支输入。这是未来泄漏反例，不是更强语言模型的证据。
