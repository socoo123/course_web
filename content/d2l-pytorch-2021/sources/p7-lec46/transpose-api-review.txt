Editorial paraphrase: The operator corresponds to the gradient of Conv2d with respect to its input, not the true inverse. Per axis output=(input-1)*stride-2*padding+dilation*(kernel_size-1)+output_padding+1. Strided Conv2d can map several input sizes to one output size. output_padding selects an output size, not zero-valued padding appended to the result. For groups=1 the weight shape is [C_in,C_out,k_h,k_w], unlike Conv2d's [C_out,C_in,k_h,k_w]. Equal output shape does not imply recovered signal values. The textbook's 16->6->16 example is valid but its surrounding shape-recovery statement is not universal for stride>1.
