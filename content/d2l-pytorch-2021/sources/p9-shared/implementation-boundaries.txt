PyTorch Seq2SeqEncoder.forward ignores *args and runs all padded steps. The bounded P9 model uses pack_padded_sequence so encoder terminal state excludes padding.
PyTorch Seq2SeqDecoder.forward constructs context=state[-1].repeat(X.shape[0],1,1) anew on each call. Whole-sequence teacher forcing keeps the original context for that call, while tokenwise calls feed updated state. P9 retains immutable encoder context separately from evolving decoder hidden; this is an explicit editorial repair, not literal execution of the original predict helper.
MaskedSoftmaxCELoss returns (unweighted_loss*weights).mean(dim=1). P9 instead divides sum of valid target NLL by number of valid target tokens, including EOS. The original mean over padded width followed by token counting is not reported as equivalent.
Textbook BLEU uses weights 1/2**n; P9 diagnostic corpus BLEU-2 uses uniform weights1/2, fixed order2 and no smoothing, separately documented from sentence-level smoothed effective-order values.
