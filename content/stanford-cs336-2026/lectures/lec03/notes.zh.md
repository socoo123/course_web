# 模型架构不是配方清单：形状、预算与稳定性的共同约束

## 1. 先确定比较的东西，再选择组件

假设两个模型验证损失不同：一个采用门控 MLP，另一个不用。能立即得出“门控更好”吗？不能。若前者多了一张同样大的矩阵，它也可能只是用了更多参数和计算。若两者参数一样，但一个每秒处理的 token 更多，那么固定训练时长下的数据预算仍不同。

架构选择至少同时约束四件事：

- **表达与泛化**：在相同数据、评测协议下能学到什么？
- **可优化性**：梯度与激活能否保持可用，是否能完成计划中的训练？
- **训练代价**：每个 token 要做多少计算，保存什么中间量？
- **使用代价**：生成时每一步要读取多少参数和历史状态？

L01已经讨论“模型看见什么”，L02建立了资源账本；本页把它们用于设计一个现代稠密 decoder。课堂的模型调查提供合理起点，**流行程度不是因果消融，默认值不是数学定律**。原讲顺序及问答见[课堂导航与有限译述](#/c/stanford-cs336-2026/lec/lec03?v=draft)。

本页只保留完成架构推理所需的接口：标准 Attention 与 RoPE 的论文精读统一在[本讲材料](#/c/stanford-cs336-2026/lec/lec03?v=materials)；位置/长度实验见[ext03](#/c/stanford-cs336-2026/lec/ext03?v=notes)，优化器动态见[ext02](#/c/stanford-cs336-2026/lec/ext02?v=notes)。不把这些内容重新铺成第二份论文或优化器教程。

## 2. 用一份形状契约描述模型

令 $B$ 为 batch，$T$ 为序列长度，$d$ 为残差流宽度，$m$ 为 MLP 中间宽度，$L$ 为层数，$V$ 为词表大小。再把常被混写的三个注意力参数拆开：查询头数 $h_q$、键值头数 $h_{kv}$、每头维度 $k$。本页假定 key 与 value 的每头维度都为 $k$。

| 对象 | 形状 | 必须满足的接口 |
| --- | --- | --- |
| token ID | $(B,T)$ | 整数索引，不是连续特征 |
| 嵌入表 $E$ | $(V,d)$ | 查表后为 $(B,T,d)$ |
| 残差流 $X$ | $(B,T,d)$ | 每个分支回加前必须恢复宽度 $d$ |
| 查询 $Q$ | $(B,T,h_q,k)$ | 每个 query head 各自形成注意力分布 |
| 键、值 $K,V_{\mathrm{attn}}$ | $(B,T,h_{kv},k)$ | GQA 中多个 query head 共享一组 K/V |
| 每头输出 | $(B,T,h_q,k)$ | 合并后宽度 $h_qk$，再投影回 $d$ |
| 门控 MLP 两路中间量 | 各 $(B,T,m)$ | 逐元素相乘，不能把矩阵乘法误作门控 |
| 输出 logits | $(B,T,V)$ | 训练目标移位与有效 token 计数另见训练桥接 |

这里用 $V_{\mathrm{attn}}$ 区别注意力的 value 张量和词表大小 $V$。轴拆分与广播的基础规则见[张量形状桥接](#/c/stanford-cs336-2026/lec/bridge01?v=notes)。

### “头数必须整除模型宽度”是实现约定，不是注意力定理

当代码先投影到 $d$ 再等分为 $h_q$ 个头时，当然要求 $h_qk=d$。但也可以先投影到 $h_qk\ne d$，然后用输出矩阵恢复残差宽度。因此数学接口只要求矩阵尺寸匹配；具体实现或官方作业可能有更严格的约定，不能借“数学上允许”忽略接口要求。

在常见的均匀 GQA 分组中，还要求 $h_q$ 可被 $h_{kv}$ 整除。减少 $h_{kv}$ 不等于减少 $h_q$：查询仍有原来的头数，只是读取的键值表示共享了。

## 3. 归一化：先问它在不在残差主路径上

把注意力或 MLP 抽象成分支 $F$，归一化记为 $N$。三个结构的区别是：

$$
\begin{aligned}
\text{pre-norm:}\quad &y=x+F(N(x)),\\
\text{residual post-norm:}\quad &y=N(x+F(x)),\\
\text{分支后归一化:}\quad &y=x+N(F(x)).
\end{aligned}
$$

第三种也可能被称为某种 post-norm，但它与第二种不是同一个计算图。不要只凭“pre/post”标签判断梯度路径。

![归一化位于分支还是残差和之后，会改变恒等梯度路径](assets/lec03-residual-path.svg)

*图：编者自绘，用抽象分支 F 比较两种残差结构。不是原讲义图或课堂截图；箭头表示前向依赖，不表示实测梯度大小。*

**编者的局部推导。**令 $J_F,J_N$ 表示相应位置的 Jacobian，则：

$$
\begin{aligned}
J_{\rm pre}&=I+J_FJ_N,\\
J_{\rm post}&=J_N(I+J_F).
\end{aligned}
$$

pre-norm 保留了一个不经过归一化的恒等项；residual post-norm 的整条路径都要乘归一化的 Jacobian。这解释了课堂“保持残差主路径干净”的直觉，但**没有证明 pre-norm 绝不梯度爆炸、每层梯度相等，或不再需要 warmup**。多层乘积、分支尺度、初始化和学习率仍起作用。链式法则与 autograd 的独立解释见[bridge03](#/c/stanford-cs336-2026/lec/bridge03?v=notes)。

### LayerNorm 与 RMSNorm 改了什么？

对单个 token 的特征向量 $x\in\mathbb R^d$，令：

$$
\begin{aligned}
\mu&=\frac1d\sum_i x_i,\\
\sigma^2&=\frac1d\sum_i(x_i-\mu)^2,\\
\operatorname{LN}(x)_i
&=\gamma_i\frac{x_i-\mu}{\sqrt{\sigma^2+\epsilon}}+\beta_i,\\
\operatorname{RMS}(x)_i
&=\gamma_i\frac{x_i}{\sqrt{\frac1d\sum_jx_j^2+\epsilon}}.
\end{aligned}
$$

这里沿**特征轴**归约，不混合不同 token 或 batch 样本。RMSNorm 不减均值，通常不加偏置；“RMS”是均方根，不是直接用未除以 $d$ 的欧氏范数。固定讲义第14页把分母写成范数形式，未显式写出均值因子；本页明确采用上述定义，不能直接照搬该排版当实现规格。

RMSNorm 去掉一些归约与逐元素操作，但省下的 FLOPs 占比不等于省下的时间占比。L02的解释在这里适用：小型、低算术强度操作可能主要受搬运和启动开销限制；收益还依赖融合、形状与硬件，不能从“少了一个 bias”保证整模固定百分比提速。

也不宜把两者简单排序为一个“严格更有表达力”：忽略 $\epsilon$ 时，LayerNorm 对统一平移不敏感，而 RMSNorm 一般不是。它们保留或丢弃的信息不同；课堂关于效果相近的说法是经验判断，不是函数类包含关系的证明。

## 4. 门控 MLP：三张矩阵，不能还沿用两张的预算

无偏置的普通 MLP 为：

$$
\begin{aligned}
H&=\phi(XW_1),\\
Y&=HW_2,\\
W_1&\in\mathbb R^{d\times m},\quad
W_2\in\mathbb R^{m\times d}.
\end{aligned}
$$

参数数目为 $2dm$。SwiGLU 这一门控结构则使用两条输入投影：

$$
\begin{aligned}
A&=XW_a,\qquad G=XW_g,\\
H&=\operatorname{SiLU}(A)\odot G,\\
Y&=HW_o,\\
\operatorname{SiLU}(u)&=u\operatorname{sigmoid}(u).
\end{aligned}
$$

$W_a,W_g$ 都为 $(d,m)$，$W_o$ 为 $(m,d)$，所以参数数目是 $3dm$。这里的乘法门控不是概率：$G$ 不必在 $[0,1]$，门控后的值也不必非负。“Swish/SiLU 激活”与“使用该激活的整块 SwiGLU”不是同一个对象。

若普通 MLP 用 $m_0=4d$，要让两种结构的矩阵参数相等：

$$
\begin{aligned}
2dm_0&=3dm,\\
m&=\frac23m_0=\frac83d.
\end{aligned}
$$

这就是常见 $8/3$ 比例的**预算来源**，不是宣告这个宽度普遍最优。工程实现还可能按硬件友好的倍数取整。相同矩阵参数也不保证激活峰值或墙钟时间相同：门控多出一条中间分支及逐元素计算，保存集合取决于具体实现。

### 串行与并行，不只是调度方式不同

串行 block 让 MLP 读取注意力更新后的状态；并行 block 则让两支读取同一层输入：

$$
\begin{aligned}
u&=x+A(N_1(x)),\\
y_{\rm serial}&=u+M(N_2(u));\\[2pt]
y_{\rm parallel}&=x+A(N(x))+M(N(x)).
\end{aligned}
$$

后者可能共享归一化、合并投影，但本层 MLP 看不到本层注意力刚写入的信息。因此不是把同一个函数自动并行化；它改变了依赖结构。课堂对其流行度与收益的调查不能替代在目标预算上的质量/吞吐对照。

## 5. 一张能重算的参数预算表

继续采用无偏置、两次 RMSNorm、每层一个注意力和一个 SwiGLU 的稠密 decoder；不计额外 QK norm、位置查表或其他变体。令 $e=1$ 表示输入嵌入与输出权重共享，$e=2$ 表示不共享。

| 组件 | 参数数目 | 推理依据 |
| --- | --- | --- |
| 输入/输出词表矩阵 | $eVd$ | 共享时只有一份参数，但输出计算仍存在 |
| $W_Q,W_O$ | $2dh_qk$ | 分别从 $d$ 到 $h_qk$、再回到 $d$ |
| $W_K,W_V$ | $2dh_{kv}k$ | 两个键值投影，GQA减少的是这一项 |
| SwiGLU | $3dm$ | 两张上投影、一张下投影 |
| 每层两个 RMSNorm | $2d$ | 每个归一化一个长度 $d$ 的缩放向量 |
| 最后一次 RMSNorm | $d$ | 进入输出投影前的归一化 |

总量为：

$$
\begin{aligned}
P_{\rm layer}
&=2d(h_q+h_{kv})k+3dm+2d,\\
P_{\rm total}&=eVd+LP_{\rm layer}+d.
\end{aligned}
$$

当 $h_q=h_{kv}$ 且 $h_qk=d$，注意力矩阵为 $4d^2$；取 $m=8d/3$，MLP 为 $8d^2$。因此常见的“每层约 $12d^2$”只是一组特定假设下的主项，**不是任何 Transformer 都成立的公式**。GQA、不同中间宽度、词表、额外归一化都会改账。

### 编者自拟小预算：参数和 KV cache 分开算

取 $d=96,m=256,L=4,V=1000$，$h_q=6,k=16,h_{kv}=2$，输入输出共享权重。则：

- 注意力矩阵：24,576 参数/层。
- SwiGLU：73,728 参数/层。
- 两个 RMSNorm：192 参数/层。
- 总计：490,080 参数，包括96,000个词表参数和96个最终归一化参数。
- 若仅把 $h_{kv}$ 改为6，变为 MHA，总参数为539,232，相差49,152。

下面只有整数记账，不创建模型、不实现作业模块，也不运行训练。给出的输出是**解析预期，不作为实测性能或课程实验结果**。

```python
# 独立预算机制例，不是A1实现。
d, m, layers, vocab = 96, 256, 4, 1000
hq, hkv, k = 6, 2, 16
attn = 2 * d * (hq + hkv) * k
mlp = 3 * d * m

```

## 6. GQA 的动机：每步少搬历史，不是假装没有历史

自回归生成第 $t$ 个新位置时，新 query 要与过去允许访问的 keys 做比较，再聚合对应 values。常规 **KV cache 保存每层历史 K 和 V，不保存 Q，也不是保存历史 $QK^\mathsf T$ 分数矩阵**。缓存使过去位置的投影和隐藏状态不必重新计算，但新 query 仍需读取历史 K/V。

若每个 K/V 元素占 $s$ 字节，缓存长度为 $T$，等长 batch 的逻辑载荷为：

$$
M_{\rm KV}=2BLT h_{kv}k s.
$$

前面的2来自 K 与 V 两份，不是某个 dtype。上例的 GQA 为128 KiB，改用六个 KV 头的 MHA 为384 KiB；在相同其他条件下，KV 缓存缩小三倍。

| 方案 | 查询头 | 键值头 | 核心取舍 |
| --- | --- | --- | --- |
| MHA | $h_q$ | $h_q$ | 每头独立 K/V，缓存较大 |
| GQA | $h_q$ | $1<h_{kv}<h_q$ | 同组 query 共享 K/V |
| MQA | $h_q$ | $1$ | 最大程度共享 K/V，表示约束更强 |

GQA 没有把 query head 数或每头注意力分布数同时除掉；二次配对主项不随 $h_{kv}$ 等比例下降。它减少了 K/V 投影参数和需要保留/读取的历史表示。若底层实现把共享的 K/V 真的复制成每个 query head 一份，物理内存与搬运收益也可能丢失。

**编者对课堂表述的校正。**77:25–77:59字幕把缓存描述成过去的 key/query 或已有分数子矩阵，不能作为 KV cache 的正确存储定义。课堂意图是解释“复用过去计算”，本页用新 query 的依赖关系澄清具体缓存对象；未核音，不判断是口误还是字幕问题。

### 长序列的平方来自 $T$，不是来自 $d$

采用普通 MHA、$h_qk=d$，一次前向中的稠密主项为：

$$
\begin{aligned}
F_{\rm projections}&\approx8BTd^2,\\
F_{QK,AV}&\approx4BT^2d.
\end{aligned}
$$

前者是四张投影矩阵；后者是 $QK^\mathsf T$ 与注意力权重乘 V 的两次收缩。因果三角的具体实现可以改变常数，但不改变长度的二次量级。**$d^2$ 不是“注意力对序列长度平方”的来源**。长上下文时，不能只用参数数目推断计算量。

这里也不沿用讲义里的算术强度近似作为硬件保证：它使用了长度相对宽度的假设、简化的存取边界，且没有明确所有 dtype 与融合条件。第60页是在累计生成过程上记账，不应把其中的 $T$ 因子误当单步公式。具体性能测量方法回到[L02](#/c/stanford-cs336-2026/lec/lec02?v=notes)。

## 7. 位置与窗口：分别改变得分关系和可访问集合

RoPE 在各层注意力的 Q/K 上引入旋转；关键接口是：固定内容向量时，旋转后的内积中，显式位置项可以依赖相对位移。它不是把位置向量加到输入一次，也不等于“整个语言模型对绝对位置完全不敏感”。边界、因果掩码、前层产生的上下文化表示都必须同时考虑。

不带显式位置编码、且不带顺序相关掩码的自注意力具有置换等变性；一旦加入因果掩码，任意打乱位置却保持原掩码，不再是同一个问题。课堂“没有位置编码就可以任意打乱”的直觉必须放在这一限定下理解。完整旋转推导及 Attention 原论文区别见[材料精读](#/c/stanford-cs336-2026/lec/lec03?v=materials)。

滑动窗口则改变“允许看谁”。若每个位置最多看包括自身在内的 $w$ 个位置，单层配对工作可从 $O(T^2d)$ 降为 $O(Twd)$。但连续局部层的有效感受野只是逐层传播：在没有全局层等其他路径时，$L$ 层最多覆盖约 $1+L(w-1)$ 个连续位置，不能据此保证可靠检索同样远的细节。

交替局部层与全局层，让少数层恢复远程路径，减少其他层的访问成本。若每 $r$ 层中有一层全局层，配对主项可概括为：

$$
\begin{aligned}
F_{\rm pairs}\ \propto\ 
&\frac Lr T^2d\\
&+L\left(1-\frac1r\right)Twd.
\end{aligned}
$$

只要全局层占比固定且非零，整体仍有二次项，不能称其为严格线性复杂度模型。位置外推、长度评测和局部/全局对照实验归[ext03](#/c/stanford-cs336-2026/lec/ext03?v=notes)；线性注意力、状态空间与 MoE 转到[L04](#/c/stanford-cs336-2026/lec/lec04?v=notes)。

## 8. 稳定性手段各管一件事

| 手段 | 直接作用的位置 | 不应承诺什么 |
| --- | --- | --- |
| 稳定 log-sum-exp | softmax/交叉熵的数值求值 | 不会自动修复坏数据、无效掩码或已产生的非有限值 |
| 输出 z-loss | 输出 log-normalizer 的训练目标 | 不是安全求值的替代品，也不是完整 logits 上下界 |
| QK norm | 点积前的 query/key 尺度 | 不保证所有得分都为1；维度、相关性、可学习尺度仍影响分布 |
| logit soft-cap | 进入 softmax 前的得分 | 改变分布和梯度，不能假定质量无损 |
| 梯度裁剪 | 反向后的更新输入 | 不会修复已经错误的前向或 NaN |

只看 z-loss 的接口：令 $u_j$ 为输出 logits，$z=\log\sum_j e^{u_j}$。最小化的辅助项通常写成 $\lambda z^2$，加到 NLL 上。给所有 $u_j$ 加同一常数不改变 softmax，却会改变 $z$；它约束了交叉熵本身不区分的统一平移方向。固定讲义第54页还展示了**最大化**对数似然的写法，其中是减去惩罚；不能将这个负号原样搬到最小化的 loss。

soft-cap 的典型形式是 $c\tanh(u/c)$。它把有限得分限制到 $(-c,c)$，但远端梯度也会变小；更“稳”与更好的表达能力并非同义。注意力的禁止位置必须最终保持屏蔽：若先将掩码写成 $-\infty$，再对整体做有限 soft-cap，就会把禁止位置变成有限得分。这里指出运算顺序的语义陷阱，不给作业实现。

诊断应先找**第一个异常张量和首次异常步骤**，再决定改算法、精度还是超参数；具体稳定求值、梯度诊断流程见[ext01](#/c/stanford-cs336-2026/lec/ext01?v=notes)。不要靠堆叠归一化掩盖标签、掩码或归一化分母错误。

## 9. 超参数默认值应是搜索起点

- **MLP 比例**：$4d$ 的普通 MLP 与 $8d/3$ 的门控 MLP 是可解释的参数匹配起点，不是全尺度最优解。
- **头维度**：先区分 $h_qk$ 与 $d$。固定总投影宽度时改头数，不一定改变矩阵参数，但可能改变表示、分数张量数量和 kernel 形状。
- **深宽比例**：固定参数主项近似约束 $Ld^2$。增加深度意味着更多串行依赖，增加宽度改变每层矩阵与通信形状；不能只凭 $d/L\approx100$ 就给小模型或新硬件定配置。
- **词表大小**：扩大 $V$ 增加 $Vd$ 级参数与输出工作，却可能缩短相同原始文本的 token 序列。跨 tokenizer 的损失比较仍需一致的原始文本与计分单位，见[L01](#/c/stanford-cs336-2026/lec/lec01?v=notes)。
- **dropout、weight decay**：大数据单遍训练不等于绝无记忆、数据污染或过拟合。weight decay 可以影响优化轨迹而不只是缩小泛化差距；不要因名称里有“正则化”就用单一解释。与学习率的联合效应留给[ext02](#/c/stanford-cs336-2026/lec/ext02?v=notes)。

一次有用的对照必须明确固定的是参数、token、FLOPs还是墙钟时间，并记录其余量。先从可靠基线只改变一个架构轴，在相同数据与验证协议上观察质量、异常频率和实际成本；有预算时使用多个种子看波动。跨模型技术报告的表格适合筛选假设，不足以给出精确收益百分比。

完整训练闭环见[bridge06](#/c/stanford-cs336-2026/lec/bridge06?v=notes)，正式规格以[A1指导](#/c/stanford-cs336-2026/lab/a1-basics?v=guide)为准。本页不提供可提交的 Transformer、RoPE、优化器或训练器实现；AI辅助限概念/API理解。

## 10. 自测与答案

1. **$d=96,h_q=6,k=24$ 是否在数学上不合法？**
   - 合法，查询投影宽度为144，输出矩阵应从144投影回96；但未必符合某个固定实现的接口。
2. **把普通 MLP 换成门控结构，保持 $m$ 不变，是等参数比较吗？**
   - 不是，矩阵参数从 $2dm$ 变成 $3dm$，增加50%。等参数时门控宽度为原来的 $2/3$。
3. **pre-norm 为何便于梯度传播？是否保证稳定？**
   - 局部 Jacobian 中有恒等项，不必每次都穿过归一化；分支及多层乘积仍可能不稳定，所以不是保证。
4. **RMSNorm 的分母为什么必须写出均值？**
   - 标准定义控制每个特征的均方尺度。未除以 $d$ 的范数与它相差宽度相关因子，$\epsilon$ 的相对尺度也不同，不能直接混用。
5. **把六个 KV 头减为两个，查询头仍六个，所有计算都少三倍吗？**
   - 不会。KV缓存及相关投影减少，query head 的配对与聚合仍存在，MLP、词表矩阵等也不同比缩小。
6. **为什么 KV cache 不保存旧 query 或全部注意力分数？**
   - 新位置有新的 query；它需要历史 keys/values，旧 query 和旧分数不能替代新的点积。常规自回归复用的历史状态是各层 K/V。
7. **四层中一层全局注意力，另外三层局部，复杂度是否变线性？**
   - 不严格线性；仍有全局层的 $T^2$ 项。改变的是系数与局部层成本。
8. **输出概率相同，z-loss 必须相同吗？**
   - 不必须。统一平移 logits 保持 softmax 不变，却改变 log-normalizer 和相应惩罚。
9. **模型只训练一遍数据，就能取消隔离验证集吗？**
   - 不能；重复、分布差异、泄漏和优化异常依然需要独立评测。
