4. Technical author review and source caveats
- All score normalization is along keys; grouped KV head count does not replace query head count in score/FLOP ledgers.
- FLOPs versus FLOP/s, byte versus MiB/GiB, allocated versus reserved, logical payload versus actual HBM traffic and useful pairs versus executed instructions are explicitly separated.
- 12BHqSqSkd ordinary and14BHqSqSkd rematerialized forward+backward are stated matmul main terms for dk=dv, all Q/K/V gradients required, and one extra QK recomputation; softmax/scaling/mask etc. excluded or separately noted.
- Per-row LSE is not a probability or an ordinary exponential sum. Alpha=exp(m_old-m_new) is at most1; both numerator and denominator use it. Global-max-with-row-sums is distinguished from incorrectly sharing normalization across rows.
- Empty allowed sets are excluded from ordinary softmax derivation; no universal claim about any concrete all-mask backend return value. Empty tile is zero contribution; -infinity minus -infinity is not treated as safe arithmetic.
- dK=tau*dS^T*Q is checked by symbolic shape; tau included once. Worked example only covers probability/value local gradients, not an invented Q/K numerical test.
- Source text exposed FA2v1 transposition/scaling anomalies. Paper owner reported direct visual confirmation in PDF pp3-7; this slice did not visually inspect those pages. Full source errata and visual evidence belong to lec06/materials. ext05 explicitly links that home and independently derives the correct invariants rather than silently treating v1 errors as valid formulas.
- Main's interim feedback on ext04 was applied: five objects corrected to six; six-term storage sum, input dimension declaration and three FLOP expressions explicitly split across lines for mobile width.
- Event time is elapsed device timeline time, not necessarily sum of active kernels. Multistream work needs proper dependency inclusion. Profiler overhead, Compute replay/cache/clock controls and source-version boundaries are disclosed.
- All3 SVGs are original, with title/desc and theme-variable colors, no scripts/external references/backgrounds. Their geometry is explanatory, not measured capacity/time.
